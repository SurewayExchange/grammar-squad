# Grammar Squad

Interactive workbook for *Grammar Squad: How to Change Your Thinking & Behavior Through the Eight Parts of Speech* by Jessie Calvin Lee and Larry Davis.

The site teaches the eight parts of speech as a self-help practice: name the problem, replace what does not serve you, modify the behavior, and take the next action. Writing stays in the browser. Nothing is sent to a server.

## Rooms

- Learn each part, hear it read aloud, and answer a check
- Practice the 2-2-3-1 memory code, label sentences, and take the quiz
- Work hindsight and insight themes, then the briefcase and the chair
- Take a two-minute floor that begins with “It’s all business”
